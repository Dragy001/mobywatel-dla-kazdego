# mObywatel dla każdego — prototyp koncepcji

Klikalny prototyp na **mObywatel Challenge** (mobywatel.ai): nowoczesny mObywatel, w którym
starsza osoba się nie gubi (osobny **prosty widok**), a przedsiębiorca z jednoosobową firmą
może prowadzić sprawy firmy: **faktury w KSeF, podatki z wyjaśnieniem kwot, ZUS, CEIDG, dostęp księgowej**.

**Zobacz:** https://dragy001.github.io/mobywatel-dla-kazdego/

> Prototyp koncepcji. Nie jest aplikacją administracji publicznej ani oficjalną aplikacją mObywatel.
> Wszystkie osoby, firmy, numery i kwoty są fikcyjne. Nie łączy się z żadnym rejestrem.

## Uruchomienie

```bash
npm ci
npm run dev     # http://localhost:5173/mobywatel-dla-kazdego/
npm test
```
